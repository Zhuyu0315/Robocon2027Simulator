# 女娲补天 竞技赛 · 手动操作模拟器（Robocon 2027）

基于《第二十六届全国大学生机器人大赛 · 女娲补天竞技赛规则 V0》（ABU ROBOCON 2027 翻译稿）实现的**手动分区操作模拟器**。

> 用途：给参赛队用来**手动推演、练习、演示整套比赛流程**的工具。你像在真实场地上一样，操控红、蓝两队的搬运机器人 TR 和建筑机器人 BR，一步步执行“移动到某个区 → 拿取 → 放置/交接”，模拟器按耗时推进、自动判定规则并刷新场上状态与比分。

---

## 一、能干什么

你（操作者）同时操控红、蓝两队的 TR 和 BR，通过面板按钮执行竞技赛中真实的**区域移动、拿取、放置、交接、翻转、重置**动作。每点一次：

1. 先校验该动作是否合法（区域、携带上限、库存、保护法则、建塔顺序等）——**不合格立即拒绝，且不消耗时间**；
2. 合法则按设定耗时推进，完成后自动更新**地图上的塔、物品、机器人位置**，并**实时计分**。

适合赛前战术推演与规则熟悉。

## 三、操作面板

**TR（搬运，只在 地面区/传递区 活动）**
- 移动：下拉选 储存区 / 公共区 / 五色石基座 / 传递区
- 拿取：下拉选 塔基/中段 / 塔顶 / 五色石（对应源区域：储存区/公共区/五色石基座）
- 放置：放到传递区地面（下拉类型）、直接交给 BR（下拉类型）
- 回重置区

**BR（建筑，在 传递区/L1/L1公共/L2/中央基座 活动）**
- 移动：下拉选 传递区 / 中央基座 / 各建塔处
- 拿取：下拉选 塔基/中段 / 塔顶 / 五色石
- 放置：放塔基/中段（下拉选建塔处）、放塔顶（下拉选建塔处）、放五色石
- 翻转塔顶（下拉选建塔处，夺取对方塔）
- 回重置区

携带上限、区域前置、库存、保护法则等由引擎校验，**不合格直接拒绝、不占时间**。

### 手动流程示例（TR拿塔基→放传递区→BR拿→BR放L1）
1. TR 移动→储存区；TR 拿取→塔基/中段
2. TR 移动→传递区；TR 放到地面→塔基/中段
3. BR 移动→传递区；BR 拿取→塔基/中段
4. BR 移动→L1建塔处（选 R1）；BR 放塔基/中段→R1
5. 再按需 放塔顶→R1、翻转塔顶等

---

## 四、规则要点

- **建塔顺序**：塔基 → 中段 → 塔顶；塔顶需先有塔基+中段。
- **携带上限**：TR≤3、BR≤2（可在设置中改）。
- **保护法则**：≥2 座全塔、且至少 1 座在公共区（L1 公共或 L2），才能取/安放五色石。
- **翻转塔顶**：翻成己方颜色，有效夺取对方全塔。
- **记分**：TR 运送塔基/中段/塔顶到传递区 每件 +5；建塔 L1=塔基10/中段20/塔顶40、L2=20/40/80；安放五色石 +250。
- **重置归还**：回重置区时携带物放回其原区。
- **比赛**：时长可设置；结束后导出带时间戳日志 `match_log_<年月日_时分秒>.txt`；可重新开始下一场。

## 五、运行

需要 Python 3 + PyQt5。

```bash
pip install -r requirements.txt
python robocon_simulator.py
```

> 也可直接运行已打包的 **`dist\RoboconSimulator.exe`**（无需 Python）。

## 六、代码结构

| 文件 | 职责 | 依赖 |
|------|------|------|
| `robocon_data.py` | 数据/配置/常量：`Config`、携带上限、建塔处与各区**绝对像素坐标**、`BuildSlot`、`TeamState`、`Operation`、`build_operations()` | 无 |
| `robocon_engine.py` | 内部逻辑：`GameEngine`（状态 + 移动/拿取/放置/翻转/重置 + 前置校验 + 保护法则 + 记分 + 计时 + 设置存取） | 纯 Python |
| `robocon_map.py` | 地图绘制：`MapWidget`（roadmap.png 上叠加塔/物品/五色石/机器人小球） | data |
| `robocon_ui.py` | 前端：`SimulatorWindow`（紧凑面板/下拉/控件宽度`ROW_WIDTH`/参数设置/计分/时钟/日志） | data+map+engine |
| `robocon_paths.py` | 路径辅助（源码运行 / exe 打包的资源与输出目录） | 无 |
| `robocon_simulator.py` | 入口（启动 Qt 应用） | ui |

依赖单向：`data ← engine ← ui`、`data ← map`，引擎与地图都不依赖界面。

## 七、参数设置

主界面下方有：
- **「⚙ 移动时间设置」**：比赛时长、TR/BR 携带上限、地图移动时间（按**每两个地点一对**列出，TR 5 区 10 对、BR 6 区 15 对，每对一个可调）。移动耗时 = 起点→终点 两个地点之间的时间，**不再为单个移动命令设耗时**。
- **「💾 保存设置」**：写入 `robocon_settings.json`；启动自动读取，有则用，无则默认。删除该文件即回默认。

## 八、坐标 / 控件宽度微调

**绝对坐标**（roadmap.png 上，原点左上、x 右 y 下，图 1461×1351）：
- 建塔处/基座/储存区/公共区/传递区：改 **`robocon_data.py`** 的 `SLOT_POSITIONS`、`CENTRAL_BASE_POS`、`FIVE_COLOR_BASE_POS`、`RED_STORAGE_RECT`、`BLUE_STORAGE_RECT`、`FIRST_PUBLIC_CENTER`、`RED_TRANSFER_RECT`、`BLUE_TRANSFER_RECT`（每处有注释标明区域）。
- 机器人小球落点：改 **`robocon_map.py`** 的 `ROBOT_POS`（建塔处小球用 `SLOT_POSITIONS`）。

**控件宽度**：改 **`robocon_ui.py`** 顶部的 `ROW_WIDTH`（每行的 `btn/combo/spin` 宽度），红蓝两队共用。下拉框、时间框、按钮各自单独可调，文字居中。

## 九、打包成可执行 exe

使用 PyInstaller 打包成单个 `exe`，别人**无需安装 Python**，双击即用：

```bash
python -m PyInstaller --noconfirm --onefile --windowed --name RoboconSimulator --add-data "roadmap.png;." robocon_simulator.py
```

- 产物：`dist\RoboconSimulator.exe`（Windows 单文件）。
- 打包后：`roadmap.png` 打进 exe；`robocon_settings.json` 与日志写到 **exe 所在目录**（由 `robocon_paths.py` 处理）。
- 注意：单文件 exe 偶被 Windows 杀毒软件误报，属常见；介意可用文件夹模式（去掉 `--onefile`）。

## 十、常见问题

- **为什么地图 1:1 不变形？** 按 roadmap.png 原始比例缩放绘制。
- **为什么某动作点了没反应？** 会被“开始前校验”拒绝并在日志说明原因，不消耗时间。
- **按钮/下拉宽度不对？** 改 `robocon_ui.py` 顶部 `ROW_WIDTH`。
